• Этим цветом обозначены границы, в которые будет вписан лого вместе с полями. Расстояние между рамками — программно задаваемый отступ.
  • Правильно: без полей, без фона, горизонтальный, белый монохромный либо в легких градациях серого.
  • Приемлемо: небольшие поля, мелкие цветные элементы.
  • Не подходит: с широкими полями, с фоном, вертикальный, не белый, не монохромный, не svg.
